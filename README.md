# obsidian-open

Weiterleitung von `https://felixkausmann.github.io/obsidian-open/#vault=…&file=…` nach `obsidian://open`.
Google Kalender entfernt Links mit `obsidian://`, https-Links bleiben klickbar. Vault und Pfad stehen im `#`-Teil und gehen nie an den Server.
Genutzt vom Plugin `obsidian-google-sync`.
